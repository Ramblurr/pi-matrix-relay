# Extension

ClojureScript Pi extension.

## Local dev

Run from `extension/`:

- `bb lint` — run clj-kondo.
- `bb test` — compile and run Node tests.
- `bb shadow-server` — start shadow-cljs.
- `bb shadow-release` — build `dist/pi-matrix-relay.js`.
- `bb install-local-extension` — install the local build.
